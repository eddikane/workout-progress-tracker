# Overview

I created this Workout Progress Tracker to strengthen my understanding of C# and object-oriented programming while using the concept of a program I use in my everyday life to make it more personal. The program allows a user to add exercises, view a workout, calculate workout volume, save workout data to a text file, and load saved workout data back into the program.

The purpose of this software was to improve my ability to build a complete C# program using classes, objects, lists, loops, conditionals, methods, file input/output, and user input validation. I also wanted to create something related to fitness because it is an area that I am personally interested in and would also be something I could realistically continue improving in the future.


[Software Demo Video](https://youtu.be/khz_RrlJMBA)

# Development Environment

I developed this software using Visual Studio Code on my Windows, with some help of the AI assistant included in the latest updates. I used the .NET SDK to build and run the application and GitHub to manage version control and publish the project.

The software was written in C#. The program uses standard C# and .NET functionality, including List<T>, StreamWriter, File.ReadAllLines, File.Exists, loops, switch statements, classes, constructors, methods, and int.TryParse for input validation.
